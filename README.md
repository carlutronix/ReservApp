# ReservApp

Sistema de gestión de reservas deportivas desarrollado como Trabajo Fin de Grado.

## Tecnologías utilizadas

- React + TypeScript
- Node.js + Express
- PostgreSQL
- Prisma ORM
- Docker
- JWT Authentication

## Funcionalidades principales

- Registro y autenticación de usuarios
- Gestión de pistas deportivas
- Sistema de reservas
- Bloqueo de pistas por mantenimiento
- Panel de administración
- Estadísticas del sistema
- Exportación de datos en CSV
